# EcoMind AI

Smart campus energy optimization workspace with a Vite React operations dashboard and a FastAPI service layer.

## Run the frontend

```bash
cd frontend
npm install
npm run dev
```

Open `http://localhost:5173`.

## Run the backend

```bash
cd backend
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --reload
```

The API is available at `http://localhost:8000`, with interactive docs at `/docs`.
